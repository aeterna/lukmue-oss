# lukmue-oss

Open-source tools and mods from AETERNA.

เครื่องมือและ mod ที่เปิดให้ใช้ได้จาก AETERNA

- `tools/<name>/`: standalone tools
- `mods/<name>/`: mods for games and platforms that allow them

The first tool is [`project-check`](tools/project-check/), which validates each project's `project.toml`.
